## 已完成并有验证证据的实现

### Foundation

- Cargo workspace 已包含 `c64-core` 与 `c64-wasm`。
- 固定 Rust 1.97.0、edition 2024、`wasm32-unknown-unknown`、wasm-pack 0.15.0、wasm-bindgen 0.2.127，并提交 `Cargo.lock`。
- `c64-core` 使用 `#![forbid(unsafe_code)]`；Wasm ABI 为粗粒度接口，不逐周期跨 JS/Wasm。
- 已定义 Strict/Turbo 请求、profile、PAL/NTSC 虚拟时间、基础 save-state 和统一页能力/版本框架。

### Rust Strict 主机核心

- NMOS 6510：全部 256 个合法与非法 opcode、decimal、JAM、IRQ/NMI、RDY、逐周期总线和 6510 处理器端口。
- PLA、统一 64 KiB RAM、ROM/隐藏 RAM、颜色 RAM、Cartridge 地址窗口和页 generation。
- MOS 6526 CIA：计时器、TOD、串口、端口、IRQ/NMI 管线和芯片修订差异。
- VIC-II PAL 严格序列：bad line、BA/AEC、fetch、边框、精灵 DMA、碰撞、IRQ、light pen 和逐像素帧缓冲。
- SID：MOS6581/MOS8580 oscillator、combined waveform、noise/test/sync/ring、ADSR、两种滤波器、板级 RC、重采样与有界音频环。
- CIA2 已连接 Rust IEC 开集电极总线，并实现反相的主机输出及 PA6/PA7 输入。

### 1541 已完成的底层模块

- MOS 6522 VIA Rust 实现已通过 100,015 次 TypeScript 随机差分。
- Rust 与 TypeScript 均逐字节匹配 VICE revision 46176 的 40 个 PB7 页面和 24 个 timer/IFR 页面；参考数据来自真实 1541。
- IEC 总线使用固定容量、generation 校验和无热路径分配的开集电极聚合模型。
- 1541 VIA1 板级接线已实现 DATA/CLOCK 7406 反相、ATNA 门、设备地址位和 ATN→CA1 反相边沿。
- 16 MHz GCR 读写分离电路已实现 UE7/UF4 分频、磁通滤波、同步检测、弱磁通确定序列、写移位和 BYTE READY，并通过 100,008 次 TypeScript/Rust 差分。
- D64 35..42 轨解析、错误字节、写保护、GCR 编解码、标准原始磁道生成和扇区回解码已进入 Rust，并通过 Rust 单元测试。

### 已通过的关键验证

- `cargo fmt --all -- --check`
- `cargo clippy --workspace --all-targets --all-features -- -D warnings`
- `cargo test --workspace --all-features`：96 个 Rust 单元测试、全部通过；另有 4096 opcode 单步向量测试通过。
- `npm run typecheck` 与 `npm run lint` 零警告。
- VICE VIC-II：raster IRQ、light pen 和 5 个逐像素参考帧通过。
- VICE SID noise/writeback：8 个固定参考用例通过。
- 现有 TypeScript 全参考链在本阶段前已通过；续接后每完成一个外设仍须重新运行聚合门禁。

## 尚未完成，禁止误报完成

1. 1541 VIA2、磁盘机构、D64/G64 可写媒体、2 KiB RAM/ROM 地址译码、独立 6502 调度、整数主机/驱动器时钟同步尚未组合成 Rust 整机。
2. Rust 1541 尚未跑通仓库的完整 VICE `verify:drive` 端到端集合；新 D64 GCR codec 还应补 TypeScript/Rust 固定数据差分。
3. Datasette/TAP、Cartridge/EasyFlash、REU/DMA 尚未完整迁移到 Rust 生产核心。
4. save-state 目前没有覆盖全部 VIC/CIA/SID/Drive/媒体内部状态。
5. 浏览器生产路径尚未完全切换到 Rust/Wasm；TypeScript 硬件仍是迁移期 oracle，不能提前删除。
6. Turbo 目前主要完成公开请求模型、槽位/时钟基础和内存 generation；BusBridge 精确退出、block cache、uop IR、lazy flags、fusion、deopt 与性能门槛尚未完成。
7. W65C816/SuperCPU、VM Enhanced 内存与 DMA 尚未实现。

## 下一阶段固定顺序

### 1. 完成 Rust 1541 整机

1. 实现 `Drive1541Mechanism`：半轨步进、马达、转速区、角位置、插拔盘写保护脉冲、BYTE READY 电平与 SO 边沿。
2. 实现 VIA2 板级接线：PA 数据总线、PB stepper/motor/LED/write-protect/speed/sync、CA2 byte-ready enable、CB2 read/write mode。
3. 实现 G64 parser/serializer 和逐字节可变速度图；D64 原始轨写入只有显式校验成功后才能投影回扇区。
4. 实现 1541 memory map：2 KiB RAM 镜像、VIA1 `$1800-$1BFF`、VIA2 `$1C00-$1FFF`、16 KiB ROM 镜像和 open-bus latch。
5. 用同一个 Rust NMOS CPU 建立独立 1541 6502 机器；每个 CPU 总线周期前推进 mechanism 与两颗 VIA，边界采样 IRQ，BYTE READY 边沿驱动 SO。
6. 用整数有理数把 PAL/NTSC 主机周期同步到 1 MHz drive 时钟，保持 IEC 因果顺序。
7. 先加 TypeScript/Rust 差分，再运行 VICE `verify:drive`、IEC delay、write-protect、disk-change、HLS 和 format。

### 2. 完成剩余 Strict 外设

1. Datasette/TAP/Writable TAP 和 6510 port motor/write/sense/read 接线。
2. Cartridge CRT、普通 8K/16K/Ultimax、EasyFlash bank/flash 状态。
3. REU DMA、VIC 优先级、页 generation 与总线所有权。
4. 扩展版本化 save-state，使所有芯片、媒体位置、总线线电平、IRQ 管线和确定性噪声状态可重放。
5. 全参考门禁通过后才把生产 Strict 后端切换为 Rust/Wasm；TypeScript 硬件仅留作测试 oracle，不留隐式 fallback。

### 3. Turbo、运行时与扩展体系结构

1. 先用简单指令执行器证明 Turbo 虚拟时间和 BusBridge 语义，再实现 block/uop 优化。
2. 加入预解码、页 guard、热后继、分支目标缓存、安全 fusion、lazy flags、延迟写回和精确 deopt；MMIO 永不推测。
3. Worker 使用粗粒度命令、Transferable 双缓冲；SAB/SIMD 只作 bit-identical 可选路径。
4. 达到 BASIC ≥10×、纯 RAM ≥15×、通用 I/O ≥3× 后再标记 Turbo 稳定。
5. 最后实现完整 W65C816/SuperCPU，再实现无自定义 opcode 的 VM Enhanced capability 与 DMA。

## 不可违反的约束

- 不修改、伪造或批量刷新历史日期；普通修改保留旧日期，新建/实质重构文件使用实际日期和作者。
- Rust、rustc、Clippy、TypeScript、ESLint、Wasm build 不允许任何 warning，也不使用全局 suppression 伪造零警告。
- 不针对软件名称、ROM、磁盘哈希或 benchmark 特判；优化只依据公开地址属性、事件和运行时热度。
- `c64-core` 保持 safe Rust；若 Wasm facade 最终确需 unsafe，必须最小隔离并增加边界测试。
- 固定外部参考版本与 SHA-256；不得用项目自身输出替代 VICE/真实硬件 oracle。
- 每项顺序：根因测试 → 实现 → 本地全门禁 → commit/push → 远端 CI；CI 通过后才关闭对应 issue。
- 未达到相应验收条件时，不宣称完整迁移、完整兼容或稳定。
